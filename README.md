# Portfolio — Fattima Goffe

**Live:** https://funmi-ai.github.io/portfolio/

A short, swipeable presentation for a Business Development Representative application at Temporal: a real stakeholder-qualification lesson, a Niyo-inspired lead-qualification prototype you can run in the browser, a seven-agent content workflow, and why reliable workflow execution matters.

A single static `index.html` with no build step. The lead-qualification demo is a browser-side simulation of the decision logic in [niyo-lead-crm-poc](https://github.com/Funmi-ai/niyo-lead-crm-poc), using synthetic data. Navigate with swipe, the arrows, ← → keys, or links like `#qualification`.
